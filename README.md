# Nepal Gold & Silver Price API

A free, lightweight, real-time Nepal Gold and Silver rates API deployed on Vercel.

## Features
- Fetches live Hallmark Gold, Tejabi Gold, and Silver prices in NPR.
- Automatically cached for 1 hour via Vercel Edge Network CDN.
- Fast, 100% free, and zero server maintenance.

## Endpoint
- `GET /api/gold`
